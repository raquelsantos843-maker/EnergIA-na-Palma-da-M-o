# EnergIA na Palma da Mao
## Aplicação web para monitoramento inteligente de consumo de energia életrica residencial.

O EnergIA é uma proposta de assistente inteligente que utiliza recursos de Inteligência Artificial para auxiliar famílias no acompanhamento e controle do consumo residencial de energia elétrica em kWh.

O objetivo é permitir que o usuário acompanhe seu consumo, visualize estimativas de gastos e receba alertas preventivos, facilitando o planejamento financeiro e incentivando o uso consciente da energia.
